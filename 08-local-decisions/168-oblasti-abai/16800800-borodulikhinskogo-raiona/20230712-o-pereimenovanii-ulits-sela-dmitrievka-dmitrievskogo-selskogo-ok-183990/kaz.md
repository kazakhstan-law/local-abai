# Бородулиха ауданы Дмитриевка ауылдық округі Дмитриевка ауылының көшелерін қайта атау туралы

Қазақстан Республикасының «Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Заңының 14-бабының 4) тармақшасына сәйкес, халықтың пікірін ескере отырып және Абай облысының ономастикалық комиссиясының 2023 жылғы 28 наурыздағы қорытындысы негізінде ШЕШТІМ:

1. Бородулиха ауданы Дмитриевка ауылдық округі Дмитриевка ауылының көшелері қайта аталсын:

   «Ленин» көшесі «Абай» көшесіне;

   «Киров» көшесі «Жібек Жолы» көшесіне;

2. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

3. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Дмитриевка ауылдық округінің әкімі**

**Қ. Нұрлыбеков**
