# Абай облысы Бесқарағай ауданы Малая Владимировка ауылдық округінің Малая Владимировка ауылының және Бозтал ауылының көшелерін қайта атау туралы

Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін - өзі басқару туралы» Заңының 35–бабы 2–тармағына, Қазақстан Республикасының «Қазақстан Республикасындағы әкімшілік–аумақтық құрылысы туралы» Заңының 14–бабы 4) тармақшасына сәйкес, 2023 жылғы 28 наурыздағы Абай облыстық ономастикалық комиссиясының қорытындысы негізінде және Малая Владимировка ауылы және Бозтал ауылы тұрғындарының пікірін ескере отырып ШЕШТІМ:

<a id="p1"></a>

1. Малая Владимировка ауылдық округінің Малая Владимировка ауылы көшелері қайта аталсын:

   «Ленин» көшесі «Шәкәрім» көшесіне;

   «Крупская» көшесі «Әлия Молдағұлова» көшесіне;

   «Киров» көшесі «Аманат» көшесіне;

   «Калинин» көшесі «Достық» көшесіне;

   «1Май» көшесі «Аққу» көшесіне;

<a id="p2"></a>

2. Абай облысы Бесқарағай ауданы Малая Владимировка ауылдық округінің Бозтал ауылында «Ленин» көшесі «Дінмұхамед Қонаев» болып өзгертілсін.

<a id="p3"></a>

3. Абай облысы Бесқарағай ауданы Малая Владимировка ауылдық округінің Бозтал ауылындағы атаусыз көшелерге атау берілсін:

   «Ыбырай Алтынсарин»;

   «Бауыржан Момышұлы»;

   «Мәңгілік Мәметова»;

   «Атамұра»;

   «Роза Бағланова».

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Малая Владимировка ауылдық округінің әкімі**

**С. Асылханова**
